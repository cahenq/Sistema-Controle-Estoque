<h1> Sistema de Controle de Estoque</h1>

<h2> Sobre</h2>
<p>Projeto desenvolvido como atividade prática da disciplina de <strong>Programação Orientada a Objetos</strong> do curso de <strong>Ciência da Computação</strong>. O sistema simula o gerenciamento de um estoque, permitindo o cadastro e a organização de diferentes categorias de produtos, aplicando os principais conceitos da POO em Java.</p>
